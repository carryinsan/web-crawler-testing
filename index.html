How to use this search correctly

Use natural questionsWrite the actual information need, not just keywords. Example: “What are the latest central-government startup schemes available to Indian students?”
Ask for freshness explicitlyWords like “latest”, “today”, “current”, “recent”, or a concrete date help the router prioritize fresh sources.
Request official evidenceFor law, GST, taxes, schemes, notifications, policy, and public administration, mention “official source” or use Government mode.
Use Deep only when neededDeep mode creates more query variants and verifies more top pages. It can increase latency and upstream requests.
Use more results for discovery1–5 is useful for a narrow lookup. 10–20 is a good research range. 30–40 is for broad source collection and comparison.
Read extracted contentVerified HTML pages can expose extracted text in the result inspector. This is useful for feeding source text into an AI answer stage.

API usage

The crawler accepts GET or JSON POST. The examples below match the deployed endpoint contract.

GET

/api/crawler?query=latest%20AI%20news%20in%20India&count=20&mode=auto&type=mixed&verify=true&deep=false&ai=auto

POST JSON

{ "query": "latest AI news in India", "count": 20, "mode": "auto", "type": "mixed", "verify": true, "deep": false, "ai": "auto", "commonCrawl": false }

Returned result shape

{ "rank": 1, "title": "…", "url": "https://…", "domain": "example.com", "type": "web|news|video|gov|doc", "source": "bing|duckduckgo|…", "snippet": "…", "publishedAt": "ISO-or-null", "freshness": "last_24h|last_7d|…", "verified": true, "httpStatus": 200, "contentType": "text/html", "trust": 0.6, "extractedText": "…" }
